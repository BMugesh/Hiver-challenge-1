2. Reconstruction Method
------------------------------
 - In-memory O(1) hash lookup mapping tweet_id -> tweet record.
 - Upward parent pointer traversal (in_response_to_tweet_id) to locate root ancestors.
 - Visited-set cycle detection during traversal.
 - Deterministic Breadth-First Tree traversal from root to assign hierarchical turn_index.
 - Preserves parent-before-child ordering across all branches.

12. Data Quality Observations
------------------------------
- Exactly 80,247 conversation threads were successfully reconstructed from 233,977 tweets.
- 100% of threads (80,247) contain both Customer and AppleSupport turns.
- 65.39% of threads are clean 2-turn exchanges (Customer Question -> AppleSupport Answer).
- 34.61% of threads contain extended multi-turn interactions (3 to 125 turns).
- Zero parent references are broken; all 153,730 parent links resolve to valid tweet IDs.
- 4,719 threads (5.88%) contain conversation branching (e.g., multiple support replies or user follow-ups).

13. Known Limitations
------------------------------
 - Multi-turn threads with branches are serialized using chronological BFS tree traversal.
 - 10,727 child pointers refer to external/untracked tweets not present in this filtered dataset.
 - Stage 2 strictly reconstructs dialogue graphs; conversation resolution status (resolved vs unresolved) is deferred to later evaluation stages.
