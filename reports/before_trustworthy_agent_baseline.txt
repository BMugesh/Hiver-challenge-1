1. EXISTING ARCHITECTURE & STAGE WORKFLOW
================================================================================
The existing pipeline operates sequentially as follows:

  [Customer Query]
        │
        ├─► [Prompt Injection Defense] (regex contextual detector)
        │
        ├─► [Multi-Issue Detection] (cross-domain symptom regex scanner)
        │
        ▼
  [Stage 4 / 7: Calibrated Intent Classifier]
        │ TF-IDF (1-3 n-grams) + Class-Weighted Logistic Regression (C=2.0)
        │ + Dense Prototype Centroids (all-MiniLM-L6-v2) + Diagnostic Rule Bonuses
        ▼
  [Stage 5: Dense FAISS Retrieval]
        │ IndexFlatIP (384-d, 5,545 indexed training cases) -> Top-10 Candidate Pool
        ▼
  [Stage 5: Domain-Aware Intent Ranker]
        │ Reranks Top-10 using Symptom Alignment, Prototype Centroid Proximity & De-biasing
        │ Selects Top-3 Aligned Historical Evidence Cases
        ▼
  [Resolution Pattern Extraction]
        │ Canonical resolution sequence mapping + historical action pattern extraction
        ▼
  [Stage 6: Grounded Reply Generation]
        │ Explicit Generation Modes: EVIDENCE_BACKED_ACTION / CLARIFY_OR_ESCALATE / SAFE_ESCALATION
        │ Synthesizes structured numbered troubleshooting steps from evidence
        ▼
  [Stage 6: Independent Grounding Verifier]
        │ Checks: Claim divergence, high-risk policy promises, and RESOLUTION_FAITHFULNESS
        ▼
  [Stage 7: Decision Engine & Frozen Safety Policy]
        │ Deterministic evaluation of safety gates:
        │ 1. High-risk grounding failure -> ESCALATE
        │ 2. Unsupported claims -> ESCALATE
        │ 3. Evidence insufficient / conflicting -> ESCALATE
        │ 4. Intent confidence < 0.60 -> ESCALATE
        │ 5. Retrieval similarity < 0.65 -> ESCALATE
        │ 6. Intent-evidence alignment < 0.66 -> ESCALATE
        │ 7. Prompt injection detected -> ESCALATE
        │ 8. Multi-issue detected -> ESCALATE
        │ Otherwise -> AUTO-HANDLE
        ▼
  [FastAPI Backend (api.py:8000) -> React Dark Chatbot UI (frontend:5173)]

2. IMPORTANT REPOSITORY FILES
================================================================================
- `src/stage1_dataset_understanding.py`: Raw dataset loading, tweet cleaning, and dialogue parsing.
- `src/stage2_conversation_reconstruction.py`: Directed conversation tree reconstruction and cycle resolution.
- `src/stage3_resolution_filter.py`: Ground-truth resolution filtering (7,922 validated resolved threads).
- `src/stage4_intent_discovery.py`: 11-class customer-centric intent taxonomy definitions and n-gram rules.
- `src/stage5_retrieval.py`: Dense sentence-transformer embeddings (all-MiniLM-L6-v2) and FAISS IndexFlatIP.
- `src/stage5_domain_ranking.py`: Domain-aware candidate reranking, prototype centroids, and contextual scoring.
- `src/stage5_multi_issue.py`: Rule-based multi-issue detection across distinct problem domains.
- `src/stage5_error_analysis.py`: Systematic error taxonomy and confusion matrix diagnostic tooling.
- `src/stage6_grounded_reply.py`: GroundedReplyGenerator, canonical resolution patterns, IndependentGroundingVerifier.
- `src/stage7_decision.py`: CalibratedIntentClassifier, DecisionPolicy, DecisionEngine, EscalationReasonCodes.
- `src/stage8_evaluation.py`: Master deterministic evaluation harness for all metrics, charts, and reports.
- `src/api.py`: FastAPI server serving `/api/support/analyze` for live customer chatbot interaction.
- `frontend/`: React + Vite dark minimalist chatbot interface with AI Analysis Technical Panel.
